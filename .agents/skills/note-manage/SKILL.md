# AI 实践笔记管理

先读取仓库根 [AGENTS.md](../../../AGENTS.md) 和 [README.md](../../../README.md)。前者规定内容与授权边界，后者是仓库入口；再按任务读取相关笔记。

## 写入与导入拆分

1. 读取人工提供或指定的素材。先确认正文、实例和附件的范围；有信息的图片也要查看。长材料按问题梳理，保留影响理解的上下文。
2. 用文件名、标签和关键词定位相关笔记，阅读候选正文后判断补充已有章节还是新建，并为笔记评估 README 中最合适的主分类。笔记存放在与分类标题同名的目录；标签用于检索，不决定目录。优先选择一处主要位置，相关主题用链接关联，不因材料类型重复建文档。
3. 若具体归档方案尚未获批，给出建议文件或章节、所属分类目录、补充或新建方式、原因、内容处理和标签，等待人工裁决。若现有分类都不合适，提出新分类的名称、边界、对应目录及 README 导航调整；获批后建立同名目录。已有明确位置或已获批方案时直接执行。只读讨论仅返回方案。
4. 按裁决整理 YAML 标签、正文与来源，按 AGENTS.md 的开篇格式让核心先于细节出现；提示词、例子和证据放在后文，不另写重复的总结。图片或附件放在笔记所属分类目录内的合适位置，在笔记中建立相对链接。原素材中的不完整链接只在目标可确认时修复；不能确认时保留原状并说明。
5. 检查受影响的关联链接；新增笔记、新分类或移动笔记后更新 README 导航。拆分材料时核对每个具体做法、重要例子、数值和附件的去向，不复制整份正文作为第二份笔记。
6. 对本次文件轻量自检：标签是否有检索价值、标题下能否一眼看到核心，做法类是否说明适用场景、实例类是否说明证据边界；再检查原意与未决状态、来源、相对链接、附件和重复正文。格式问题直接修正；语义疑点保留并报告。

报告写入位置、主要处理、仍需人工澄清的内容及检查范围。提交和推送依用户本次授权执行。

## 查询

1. 区分自然语言主题查询与明确的标签筛选。多个标签要求“同时包含”时取交集，“任一包含”时取并集；只列标签而未说明关系时默认交集，并在结果中说明。
2. 从分类目录和文件名入手，用 `rg` 搜索相关标签、主题及同义关键词；标签筛选须读取 YAML `tags` 列表确认，不把正文中的同名词误认为标签。主题查询继续阅读正文和关联链接；涉及实例或图片时也检查对应分类目录中的笔记和附件。
3. 返回笔记链接、匹配依据和简短内容提示，区分直接命中与关联结果。未找到时说明实际搜索范围，不据此宣称整个仓库没有相关内容。

例如“找评审 AI 方案时如何检查尺度”，可查“评审、尺度、数值限制”并沿链接找相关笔记；若明确要求同时包含“评审”“提示词”标签，则只按 YAML 标签交集筛选。
