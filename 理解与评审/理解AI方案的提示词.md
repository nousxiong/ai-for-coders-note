# 理解 AI 方案的提示词

**核心：先问清方案怎样解决问题、适用到哪里，再用例子、示意图和成熟方案对比补足理解。**

适用：评审、学习或落地方案时，把问题发给 AI 或方案作者。按需选问；将 `xxx` 换成当前方案、具体做法或成熟方案。

理解方案后，可用 [评审 AI 方案的做法](评审AI方案的做法.md)继续质疑；追问过程见[理解 AI、质疑 AI 实例](../治理与实例/理解AI、质疑AI实例.md)。

## 常用提示词

```
简洁解释这个方案如何解决了问题，配合举例子和示意图。
这个方案的适用范围是什么？
有没有借鉴相关成熟方案？
```

## 按需追问

问适用范围时结合具体场景；问示意图时说明要看流程、几何位置还是模块关系；修 bug 时补问新旧实现的关键差异。

```
简洁解释 xxx，它都做了什么。

请举例子来说明。

请绘制 xxx 的示意图（流程、几何位置等）来帮助我理解。

xxx 成熟方案，是否可以借鉴？

（在修改问题、bug 的情况下）请对比修改方案和旧有实现的关键差异，并列举出来。
```
